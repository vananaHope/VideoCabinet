# 앱 아이콘 방향

지금 쓰는 결정은 맨 위 "2026-11-01 재결정(VideoCabinet, #343)"이다. 그 아래 #303 절은 앞선 결정의 기록으로 남긴다.
두 번의 시안 모두 D안이 있어 "#303 시안 D(빛줄기)"와 "#343 시안 D(자막 서랍)"로 구분한다.

## 2026-11-01 재결정(VideoCabinet, #343)

2026-11-01 사용자가 앱 이름을 **VideoCabinet**으로 바꾸고, 아이콘으로 **#343 시안 D(자막 서랍)**를 골랐다.

- `cabinet-d-subtitle-drawer.png`: 고른 시안(Codex 이미지 생성, 512px로 줄임). 인디고 판 위의 흰 서랍 앞면에 자막 두 줄과 작은 재생 삼각형이 있다. 방향을 정하는 참고 이미지일 뿐이며 배포 아이콘으로 쓰지 않는다. `assets/icon/`에 벡터 원본과 손본 PNG로 다시 그렸다.
- `cabinet-preview-board.png`: 시안 5개(A 빛나는 서랍, B 재생 손잡이, C 입체 캐비닛, #343 시안 D(자막 서랍), E 열린 문)를 16·24·32·48px 실제 크기로 밝은·어두운 작업 표시줄 위에 놓고 오른쪽에 256px을 함께 보인 미리보기 판.
- 원본은 [gist](https://gist.github.com/vananaHope/d21c3b8a12b9ceea3d75153d210ea30e)에 있다.

### 고른 이유

- 16~24px에서도 또렷하고, 자막이라는 이 앱의 특징이 드러난다.
- 앞선 '상' 글자 마크는 아이콘만 봐서는 영상 앱으로 읽히지 않고(賞·上 등), 기본 글꼴 글자를 판에 채운 모양이라 임시 이미지처럼 보였다. 어두운 판 위 인디고 글자는 3.17:1로 탁해 보였다.

### 다시 그리며 바꾼 점

- 시안의 인디고~보라 그라데이션을 DESIGN.md의 "인디고 하나" 규칙에 맞춰 `primary`(#4f46e5) 단색 판으로 바꿨다. 흰 서랍과 판은 6.3:1이다.
- 시안의 "흰 서랍 안 어두운 인디고 패널"은 두지 않고, 자막 두 줄과 재생 삼각형을 흰 서랍 위에 판 색으로 뚫었다. 인디고를 한 가지로 두고 16px에서도 읽히게 하려는 것이다.
- 판은 어두운 작업 표시줄(#202020)과 2.6:1이라, 이전 아이콘과 같은 `input` 회색 테두리를 둘러 두 작업 표시줄 모두 3:1을 넘게 했다(DESIGN.md "App Icon").
- 트레이 아이콘은 같은 판·테두리에 서랍 앞면과 자막 두 줄만 남겼다.

## 2026-10-28 결정(#303, 지금은 쓰지 않음)

2026-10-28 사용자가 **E안: 한글 '상' 글자 마크**를 골랐다. 당시 앱 이름은 "상영실"(#301)이었다.

- `icon-e-hangul.png`: 고른 시안(Codex 이미지 생성, 512px로 줄임). 방향을 정하는 참고 이미지일 뿐이며 배포 아이콘으로 쓰지 않는다. #304에서 벡터 원본으로 다시 그린다.
- `preview-board.png`: 시안 5개(A 스크린, B 커튼, C 책갈피, #303 시안 D(빛줄기), E 한글 '상')를 16·24·32·48·256px 실제 크기로 밝은·어두운 작업 표시줄 위에 놓은 미리보기 판. 맨 오른쪽 칸은 트레이 크기로 그대로 줄인 모습이다(트레이용 단순화는 #305).

### 고른 이유

- 앱 이름 "상영실"과 바로 이어지고, 재생 삼각형·필름 모양을 쓰는 다른 미디어 앱과 가장 뚜렷하게 구별된다.
- 24px 이상에서는 글자가 선명하다.

### #304·#305에서 고칠 점

- 16px에서 획이 살짝 뭉개진다. 작은 크기 원본은 획 굵기와 'ㅇ' 속 공간을 픽셀에 맞춰 따로 다듬는다.
- 어두운 판(#18181b)이 어두운 작업 표시줄(#202020)에 묻힌다. 판 가장자리 대비를 맞춘다(픽셀 검사 3:1 기준).
- 색은 DESIGN.md의 인디고(#4f46e5) 하나를 쓴다. 시안의 미세한 색 편차·질감은 벡터로 다시 그리며 없앤다.
- 트레이 아이콘은 판 없이 글자 마크만 쓰는 쪽을 먼저 검토한다(#305).
