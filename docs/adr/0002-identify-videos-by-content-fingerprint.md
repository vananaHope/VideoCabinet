# 영상을 경로가 아니라 파일 내용의 지문으로 구별한다

사용자는 탐색기에서 영상 파일의 이름을 바꾸거나 다른 폴더로 옮기는 일이 잦고, 그때마다 태그·하이라이트·자막·시청 기록이 사라지면 안 된다. 그래서 영상의 정체성은 파일 내용의 지문(파일 크기 + 앞·중간·뒤 일부를 읽은 부분 해시)으로 정하고, 경로는 영상에 딸린 **위치**로만 다룬다. 같은 내용의 복사본은 위치가 여럿인 영상 하나이며, 위치가 모두 사라지면 기록을 지우지 않고 "파일 없음" 상태로 둔다.

## Consequences

- 경로 기준보다 등록이 느리다(파일마다 일부를 읽어야 한다). 전체 해시가 아니라 부분 해시를 쓰는 이유다.
- 파일 내용을 다시 인코딩하거나 잘라내면 다른 영상이 된다. 의도된 동작이다.
