# 번역은 API 키가 아니라 구독 CLI(codex/claude)로 처리한다

번역 자막은 외부 LLM API로 만드는 것이 일반적이지만, 사용자는 이미 ChatGPT와 Claude 구독을 쓰고 있어 별도 API 비용을 내고 싶어 하지 않는다. 그래서 번역은 `codex exec` 또는 `claude -p`를 백그라운드에서 호출해 처리하고, 기본값은 Codex, 설정에서 Claude로 바꿀 수 있게 한다.

## Consequences

- 구독 사용량 한도를 코딩 작업과 나눠 쓴다. 한도에 걸리면 번역 대기열은 멈췄다가 나중에 이어서 처리해야 한다.
- 해당 CLI가 설치·로그인되어 있어야 번역이 동작한다. 받아쓰기(원어 자막)는 CLI와 무관하게 로컬 GPU에서 돈다.
